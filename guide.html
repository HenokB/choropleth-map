Data format

Numeric data: 2 required columns

Country,Value
Canada,72
Ethiopia,85
Japan,88

Country: a country name or ISO code. Value: a number. Extra columns are ignored. Zero and negative values work; repeated country rows are summed. Invalid rows are reported.

Download sample.csv · 2 columns, 22 rows, synthetic values across all seven continents.

Language counts: 2 required columns, 1 optional

Code,Countries Spoken
en,"Canada,United States"
fr,"Canada,France"

Code and Countries Spoken are required for this format. An optional third column, Language, can hold the display name. A Language column can also replace Code. Each code is counted once per country.

Download the 3-column language example

Excel

XLSX uses the same columns. The first 25 nonempty rows of each sheet are searched for headers. Language-code sheets are preferred, then the largest matching sheet. Export a specific sheet as CSV to choose it explicitly. Formulas need saved, cached results; XLS and encrypted workbooks are unsupported.

Export

SVG: vector artwork with a transparent background. PNG: a 2400-pixel-wide image on white. CSV: all imported country totals.

Include title & caption controls both the preview and image exports. Edit their text under Appearance → Title & caption. Legend and country names have separate switches. Turn all three off for map outlines and colors only.

Map data

242 country and territory features from Natural Earth 1:50m, v5.1.2 (public domain). Boundaries follow its default de facto representation. Small territories may be generalized or absent.

Continent views crop outlying areas; use World for all features. Russia, Türkiye, Kazakhstan, Georgia, and Azerbaijan appear in both Europe and Asia. Offshore territories are grouped geographically. The scale uses all imported values so colors stay comparable between views.

Files are processed in your browser. Refreshing clears imported data; export CSV to keep aggregated results.
